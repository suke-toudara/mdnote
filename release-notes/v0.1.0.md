mdnote の初回リリースです。Linux x86_64 向けの deb と AppImage を配布します。Ubuntu 22.04 でビルドしています。

Markdown の編集・プレビュー、PDF・HTML 書き出し、タブとフォルダ一覧、テーマとフォントの切り替えに対応しています。Claude API を使ったチャットでは、変更案を確認してから適用できます。API キーはシステムキーチェーンに保存できます。

Ubuntu・Debian 系では deb、ファイルから起動する場合は AppImage を選んでください。詳しくは [インストールガイド](https://suke-toudara.github.io/mdnote/01-install.html)をご覧ください。
