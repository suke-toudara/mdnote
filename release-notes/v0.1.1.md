Linux x86_64 向けの deb と AppImage を配布します。インストール方法は [インストールガイド](https://suke-toudara.github.io/mdnote/01-install.html)をご覧ください。

## 新機能

### ファイルを名前で探して開く（クイックオープン）
`Ctrl + Shift + P` で、ファイル名の一部を入力して候補から開けます。最近開いたファイルと、開いているフォルダ内の Markdown ファイル（サブフォルダを含む）が対象です。

### フォルダ内の全文検索
`Ctrl + Shift + F`、またはサイドバーの「検索」タブで、開いているフォルダ内の Markdown ファイルをまとめて検索できます。結果はファイルごとに並び、クリックするとそのファイルの該当箇所へ移動します。大文字・小文字の区別と正規表現にも対応しています。

### ファイルへのリンクと被リンク
- 本文で `[[` と入力すると、フォルダ内のファイルを選んでリンクを挿入できます。リンクは文書から見た相対パス（例：`[設計書](../design/設計書.md)`）で入るため、GitHub などほかの環境でもそのまま使えます。
- サイドバーの「リンク」タブに、いま開いている文書へリンクしている文書の一覧を表示します。

### 本文の右クリックメニュー
プレビュー編集の本文を右クリックすると、切り取り・コピー・貼り付け、書式（太字・斜体・取り消し線・インラインコード・文字の色）、リンクを開く、ファイルへのリンクの挿入ができます。

### 書式なしでコピー・貼り付け
- `Ctrl + Shift + C`：Markdown の記号や文字色の指定を含めず、文字だけをコピーします。
- `Ctrl + Shift + V`：Markdown やタブ区切りの表として解釈せず、そのままの文字として貼り付けます。

### Mermaid の図
コードブロックの言語を `mermaid` にすると、内容を図として表示します。図は HTML・PDF への書き出しにも含まれます。

### 集中モード
`Ctrl + Shift + Enter` で、ツールバーやサイドバーを隠して本文だけを表示します。プレビュー編集では、編集中の段落以外を薄く表示します。

### 画像の表示幅の調整
画像だけの段落にある画像は、右下のつまみをドラッグして表示幅を変えられます（ダブルクリックで元に戻ります）。幅は `![説明|320](images/a.png)` の形で保存します（Obsidian と同じ書き方です）。

### 文字の色
文字を選択すると、書式ツールバーに色のボタンが出ます。色は `<span style="color: …">` として保存するため、多くの Markdown ビューアでも色付きで表示されます。

### ターミナル
`Ctrl + J`、またはツールバーのボタンで、エディタの下にターミナルを開けます。開いているフォルダ（なければ文書のあるフォルダ）で起動します。

### タブを別ウィンドウに切り離す
タブをウィンドウの外へドラッグするか、タブの右クリックメニューの「新しいウィンドウで開く」で、別のウィンドウに移せます。未保存の変更や開いているフォルダも引き継ぎます。

## 改善
- 編集位置のカーソルを、テーマごとに目立つ色にして太くしました。

## 不具合の修正
- コードブロックの右上（言語名の表示部分）からドラッグして選択したとき、選択は見えているのに `Ctrl + C` / `Ctrl + X` でコピーできないことがある問題を修正しました。
- 画像だけの段落がある文書を編集すると、画像の代替テキストが「1.00」などの数値に書き換わる問題を修正しました。すでに「1.00」になっている代替テキストは、次に保存したときに空に戻ります。

## 注意事項
- クイックオープンのフォルダ内ファイル、フォルダ内検索、`[[` によるリンクの挿入、被リンクは、フォルダを開いているときに使えます。リンクの挿入には、文書を一度保存しておく必要があります。
- 画像の幅を変えられるのは、画像だけの段落にある画像です。幅（`|320` の部分）は mdnote と Obsidian で反映されます。ほかの Markdown ビューアでは元の大きさで表示されます。
- Mermaid の図は、テーマにかかわらず白い背景で表示します。
