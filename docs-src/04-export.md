title = "HTML・PDF・印刷"

## HTML に書き出す

ツールバーの「HTML」を押すと、プレビューの内容を HTML ファイルとして書き出します。保存方法や保存先はブラウザ・実行環境によって異なります。

画像は HTML に埋め込まれるわけではありません。書き出したファイルを別の場所で開く場合は、画像が表示されるか確認してください。

## 用紙サイズと余白を選ぶ

「印刷」「PDF」、または `Ctrl + P` で印刷設定を開きます。用紙サイズは A4・A3・Letter、余白は標準・狭い・広いから選べます。

## 印刷する

設定画面で「印刷プレビュー」を押すと、実行環境の印刷画面を開きます。プリンターや PDF への保存などを選んでください。プレビューの表示方法と選べる項目は環境によって異なります。

## PDF に書き出す

Linux のデスクトップ版では、設定画面の「PDF を書き出す」から保存先を選んで PDF を作成できます。

ブラウザで動かしている場合は、印刷画面から PDF 保存を選びます。Linux 以外のデスクトップ環境では、PDF の直接書き出しに対応していません。
