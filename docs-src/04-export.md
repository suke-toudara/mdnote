# HTML・印刷・PDF

## HTML

ツールバーの「HTML」から、プレビューの内容を単一の HTML ファイルとして保存できます。見出し、表、画像、コードブロックなどの表示を含みます。

## 印刷プレビュー

「印刷」または `Ctrl + P` を押し、用紙サイズ（A4 / A3 / Letter）と余白を選んで印刷プレビューへ進みます。プレビューでは OS の印刷ダイアログからプリンターや PDF 保存先を選べます。

## PDF

Linux デスクトップ版では「PDF を書き出す」からファイル名を指定して PDF を作成します。用紙サイズと余白は印刷設定で選べます。

ブラウザ版や直接 PDF 出力に対応していない OS では、印刷ダイアログを使って PDF に保存してください。
