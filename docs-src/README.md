mdnote は、Markdown の見た目を確認しながら、そのまま編集できるエディターです。このガイドでは、Linux での起動方法と、文章を書く・保存する・書き出すための操作を紹介します。

## はじめて使う方へ

まずは「インストールと起動」でアプリを起動してください。起動できたら「編集の基本」へ進み、ファイルを開いて文章を書いてみましょう。

## このサイトについて

ここは使い方を説明するサイトです。ブラウザ上で動くエディターは公開していません。アプリのソースコードは [GitHub](https://github.com/suke-toudara/mdnote) から取得できます。
