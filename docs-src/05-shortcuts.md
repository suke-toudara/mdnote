---
title = "キーボードショートカット"
---

アプリの主なショートカットです。ツールバーの「?」ボタンから、アプリ内でも一覧を開けます。

> **注意** ブラウザで動かしている場合、一部のキーがブラウザの操作と重なることがあります。

## ファイル

| キー | 動作 |
| --- | --- |
| `Ctrl + N` | 新規文書 |
| `Ctrl + O` | ファイルを開く |
| `Ctrl + Shift + O` | フォルダを開く |
| `Ctrl + Shift + P` | ファイルを名前で探して開く |
| `Ctrl + S` | 保存 |
| `Ctrl + Shift + S` | 名前を付けて保存 |
| `Ctrl + P` | 印刷・PDF 設定 |

## 検索

| キー | 動作 |
| --- | --- |
| `Ctrl + F` | 文書内を検索 |
| `Ctrl + H` | 置換 |
| `Ctrl + Shift + F` | フォルダ内を検索 |

## 表示

| キー | 動作 |
| --- | --- |
| `Ctrl + /` | 表示モードの切り替え |
| `Ctrl + Shift + Enter` | 集中モード |
| `Ctrl + Shift + E` | サイドバーの表示・非表示 |
| `Ctrl + J` | ターミナルの表示・非表示（デスクトップ版） |
| `Ctrl + Tab` / `Ctrl + Shift + Tab` | 次 / 前のタブ |
| `Ctrl + W` | 現在のタブを閉じる |

## 編集

| キー | 動作 |
| --- | --- |
| `Ctrl + Shift + C` | 書式なしでコピー（プレビュー編集） |
| `Ctrl + Shift + V` | 書式なしで貼り付け（プレビュー編集） |
| `[[` | ファイルへのリンクを挿入（フォルダを開いているとき） |
| `Ctrl + B` / `Ctrl + I` | 太字 / 斜体（ソース表示） |
| `Ctrl + K` / `Ctrl + E` | リンク / インラインコード（ソース表示） |
| `Tab` / `Shift + Tab` | インデント / 逆インデント（ソース表示） |
