# キーボードショートカット

macOS では `Ctrl` を `⌘` に読み替えてください。

| キー | 動作 |
| --- | --- |
| `Ctrl + N` | 新規文書 |
| `Ctrl + O` | ファイルを開く |
| `Ctrl + Shift + O` | フォルダを開く |
| `Ctrl + S` | 保存 |
| `Ctrl + Shift + S` | 名前を付けて保存 |
| `Ctrl + P` | 印刷・PDF 設定 |
| `Ctrl + F` | 検索 |
| `Ctrl + H` | 置換 |
| `Ctrl + /` | 表示モード切替 |
| `Ctrl + Shift + E` | サイドバー表示切替 |
| `Ctrl + Tab` / `Ctrl + Shift + Tab` | 次 / 前のタブ |
| `Ctrl + W` | 現在のタブを閉じる |
| `Tab` / `Shift + Tab`（ソース表示） | インデント / 逆インデント |
| `Ctrl + B` / `Ctrl + I`（ソース表示） | 太字 / 斜体 |
| `Ctrl + K` / `Ctrl + E`（ソース表示） | リンク / インラインコード |

ツールバー右端の「?」ボタンから、アプリ内でも主要なショートカットを確認できます。
