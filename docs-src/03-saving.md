# 保存と復元

## 保存

- `Ctrl + S`：現在のファイルへ保存
- `Ctrl + Shift + S`：名前を付けて保存
- ツールバーの「自動保存」：オンの場合、編集が止まると保存

未保存の内容は下書きとして定期的に記録されます。異常終了後に下書きが見つかると、次回起動時に復元できます。

## 外部変更

開いているファイルを別のアプリで変更すると、MD Note が変更を検知して案内を表示します。未保存の編集がある場合は、ディスク上の変更との差分を確認できます。

## 最近使ったファイルとセッション

最近開いたファイルや前回のタブ・フォルダを記憶し、次回起動時に復元します。ファイルを移動・削除した場合は、最近使ったファイルやタブの表示も更新されます。
